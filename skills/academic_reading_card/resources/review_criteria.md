# 對抗性審稿規準與方法學理論參照（Review Criteria & References）

本文件合併收錄「批判解剖三大核心構面審查規準」與「背後支撐之經典學術方法學參考文獻」，供 Agent 於執行文獻批判精讀時動態查閱與錨定。

## 一、對抗性審稿三大構面檢核清單（Adversarial Review Checklist）

在產出卡片【第五維度：批判性審視與方法學盲點】時，必須逐一檢核以下項目並至少提出 2 點深入批判：

### 構面一：理論依據與因果邏輯（Theoretical Coherence）
- [ ] **理論非裝飾：** 論文引用的理論模型（如 CLT, SDT, TAM）是否真正推導了研究假設，抑或只是事後硬套？
- [ ] **因果黑盒子：** 自變項如何影響因變項？是否存在未被測量的中介變項（Mediator）？
- [ ] **替代解釋排除：** 是否存在其他競爭性理論能更好解釋該實證現象？

### 構面二：方法學嚴謹度與效度威脅（Methodological Rigor & Threats to Validity）
- [ ] **內部效度：** 實驗組是否受到額外的關注、技術指導或時間傾斜（霍桑效應 / 評估者偏差）？
- [ ] **構念/工具效度：** 測量工具是否為自製未檢驗問卷？是否具備充分信度（$\alpha \ge .70$）與因素分析效度？
- [ ] **統計結論效度：** 樣本數（$N$）是否過小？是否提供精確效果量（$\eta_p^2$, Cohen's $d$）與檢定統計量？
- [ ] **抽樣偏差：** 是否採用自願參與樣本（Volunteer Bias）？流失率（Attrition Rate）是否受到追蹤？

### 構面三：生態效度與外推邊界（Ecological Validity & Boundary Conditions）
- [ ] **真實情境落差：** 實驗環境若搬遷至常態課堂或真實組織，效果是否會因系統雜訊而瓦解？
- [ ] **群體與領域邊界：** 結論在不同年齡層、不同學科背景或不同文化脈絡下是否依然成立？
- [ ] **研究空白挖掘：** 原作者承認的研究限制中，留下了哪些未解之謎，可直接轉化為我們的研究利基？
