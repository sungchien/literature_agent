# 多代理對抗式同儕審查與治理規準 (Peer Review & Governance Rubric)

本文件定義 `multi-agent-peer-reviewer` 進行三路對抗審查、防範系統性錯誤以及判定審查收斂的標準規範。

---

## 一、 三路對抗審查委員會職責與判定標準

| 審查代理角色 | 核心審查問題 | 檢核依據資產 | 必須輸出的診斷標籤與動作 |
| :--- | :--- | :--- | :--- |
| **事實稽核審稿人**<br>(Fact Auditor) | 每個統計值、年份、作者、樣本數與限制是否與原文一致？ | `03_drafts/_evidence_pack.md`、`search_paper_chunks` | 標註 `[通過]`、`[證據不足]`、`[疑似錯引]`；遇錯引立即標紅並要求退回檢索 |
| **方法學審稿人**<br>(Methodological Reviewer) | 是否忽略原研究情境邊界（如 2 小時實驗室、大學部樣本）而過度推論？ | `02_notes/literature_matrix.md`、`02_notes/research_gap_statement.md` | 標註 `[推論過度]`，指出具體調節變項或效度威脅缺口 |
| **概念結構編輯**<br>(Synthesis Editor) | 是否退回「一人一段」流水帳？段落主題句與 CARS 轉折是否清晰？ | `PROJECT.md (v0.4)`、APA 第七版規範 | 標註 `[流水帳風險]` 或 `[結構斷裂]`，建議如何重排為概念中心論證 |

## 二、 審查分流與收斂停止條件（Triage & Stopping Criteria）

為避免多代理進入「為挑毛病而吹毛求疵」或「無限潤飾空轉（Infinite Revision Loop）」，必須嚴格執行以下收斂規則：

1. **最大審查輪次上限：** 同一份章節草稿最多執行 **2 至 3 輪**「審查 $\rightarrow$ 修訂」迴圈；超過 3 輪仍存在理論立場分歧時，強制凍結交由人類 PI 裁決。
2. **兩級問題分流：**
   - **第一級（輕微修辭／格式調整）：** 如 APA 標點、轉承詞微調、補充證據編號 `[EV-XX]`，直接由撰稿代理修正。
   - **第二級（實質事實／方法缺陷）：** 如出現 `[疑似錯引]`、`[證據不足]` 或 `[推論過度]`，**禁止撰稿代理自行硬掰補救**，必須退回檢索員重查 `search_paper_chunks`，或交由人類 PI 決定刪除該論點。
3. **達標放行門檻：** 報告中 `[疑似錯引]` 數量為 **0**、所有 `[證據不足]` 已補證或刪除，且三位審稿代理針對重大缺陷均無未解異議，即可進入 PI 終局裁決閘門。

## 三、 多代理協作三大系統性風險與防禦檢核

1. **錯誤級聯累積（Error Cascading）：**
   - **風險：** 檢索員擷取片面段落 $\rightarrow$ 撰稿員誇大詮釋 $\rightarrow$ 編輯潤飾成看似權威的錯誤定論。
   - **防禦：** 事實稽核員必須**繞過 `_evidence_pack.md` 的中文摘要**，直接比對英文原文摘錄或重新呼叫 `search_paper_chunks` 抽驗。
2. **同質模型迴音室偏誤（Echo-Chamber Bias）：**
   - **風險：** 撰稿與審稿均出自同一類模型與預設語氣，可能對常見表達盲點集體視而不見。
   - **防禦：** 強制獨立上下文啟動審稿員、明確下達「假設草稿有錯，請尋找反證」的對抗性系統提示，並保留人類 PI 的最終抽樣核對。
3. **認知外包與作者主體性流失（Authorship Erosion）：**
   - **風險：** 研究者對合成初稿照單全收，失去對論文理論貢獻與論點脈絡的掌握。
   - **防禦：** 強制人類 PI 填寫 `03_drafts/ai_collaboration_disclosure.md`，並於終局裁決紀錄寫下至少兩處個人親筆修改之實質理由。
